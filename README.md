# VNU Student Survey

A simple survey web application built with **Streamlit**. Users can enter their personal information, select hobbies, choose their current subjects, and receive a summary of their responses.

## Features

- Enter name and age
- Select preferred language
- Choose hobbies
- Select gender
- Choose current subjects
- Display a summary after submission
- Simple and interactive web interface

## Built With

- Python 3
- Streamlit

## Installation

Clone this repository:

git clone https://github.com/guessswha/vnu-student-survey.git

Move into the project folder:

cd vnu-student-survey

Install Streamlit:

pip install streamlit

## Run the Application

streamlit run app.py

> Replace `app.py` with your Python file name if it is different.
